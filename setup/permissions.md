# App Registration Permissions & Configuration

## Overview

This document describes the permissions and environment variables required for the defender-vuln-agent to function.

## Environment Variables

The app registration credential must be configured via one of these sets of environment variables:

### Using Client Secret (Recommended for development)

- `DVA_TENANT_ID`: Azure AD tenant ID (e.g., `00000000-0000-0000-0000-000000000000`)
- `DVA_CLIENT_ID`: Entra app ID (e.g., `00000000-0000-0000-0000-000000000000`)
- `DVA_CLIENT_SECRET`: Client secret generated by `setup/create-app.sh`

### Using Client Certificate (Recommended for production)

- `DVA_TENANT_ID`: Azure AD tenant ID
- `DVA_CLIENT_ID`: Entra app ID
- `DVA_CLIENT_CERT_PATH`: Absolute path to the PEM-encoded certificate file
- `DVA_CLIENT_CERT_THUMBPRINT`: SHA-1 thumbprint of the certificate in hex (without spaces)

## API Permissions

### WindowsDefenderATP API (`fc780465-2017-40d4-a0c5-307022471b92`)

| Permission | Used for | Without this permission | Doctor check |
|---|---|---|---|
| Machine.Read.All | Device inventory, tags, exposure level, device value | Device queries fail; `python -m dva doctor` reports list operations unavailable | `WindowsDefenderATP Machine.Read.All FAIL unable to list machines` |
| Vulnerability.Read.All | Software vulnerabilities per machine, CVE metadata | Vulnerability discovery fails; software inventory incomplete | `WindowsDefenderATP Vulnerability.Read.All FAIL unable to query vulnerabilities` |
| Software.Read.All | Software inventory and version distribution | Software enumeration unavailable; risk assessment incomplete | `WindowsDefenderATP Software.Read.All FAIL unable to enumerate software` |
| SecurityRecommendation.Read.All | Remediation text per product | Remediation recommendations missing from output | `WindowsDefenderATP SecurityRecommendation.Read.All FAIL unable to fetch recommendations` |
| Score.Read.All | Organization exposure score and trends | Exposure score unavailable; trending analysis incomplete | `WindowsDefenderATP Score.Read.All FAIL unable to fetch exposure score` |

### Microsoft Graph (`00000003-0000-0000-c000-000000000000`)

| Permission | Used for | Without this permission | Doctor check |
|---|---|---|---|
| ThreatHunting.Read.All | Advanced Hunting queries (phase 2) | Advanced Hunting queries fail; threat intel integration unavailable | `MicrosoftGraph ThreatHunting.Read.All FAIL unable to run hunting queries` |

### Azure RBAC

| Permission | Used for | Without this permission | Doctor check |
|---|---|---|---|
| Reader on each subscription (config/sources.yaml) | Resource Graph reads for Defender for Cloud (phase 2) | Resource Graph queries fail; cloud assessments unavailable | `AzureRBAC Reader on <subscription> FAIL insufficient role on <subscription>` |

## Granting Permissions

### Admin Consent

WindowsDefenderATP and Microsoft Graph application permissions require admin consent. After running `setup/create-app.sh`, grant admin consent with:

```bash
az ad app permission admin-consent --id <APP_ID>
```

This requires a Global Administrator or Privileged Role Administrator in the tenant.

## Verification

Verify all permissions are correctly configured with:

```bash
python -m dva doctor
```

Each check prints one line in the format: `<API> <permission> ok|FAIL <detail>`

All checks must show `ok` status for the application to function.

## Setup Script

Create the app registration and service principal with:

```bash
./setup/create-app.sh --name defender-vuln-agent
```

For a dry run (print commands without executing):

```bash
./setup/create-app.sh --dry-run --name defender-vuln-agent
```

The script will output the required environment variables and manual steps.
