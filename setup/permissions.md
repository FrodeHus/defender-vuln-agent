# App Registration Permissions & Configuration

## Overview

This document describes the permissions and environment variables required for the defender-vuln-agent to function.

## Environment Variables

The app registration credential must be configured via one of these sets of environment variables:

### Using Client Secret (Recommended for development)

- `DVA_TENANT_ID`: Azure AD tenant ID (e.g., `00000000-0000-0000-0000-000000000000`)
- `DVA_CLIENT_ID`: Entra app ID (e.g., `00000000-0000-0000-0000-000000000000`)
- `DVA_CLIENT_SECRET`: Client secret generated by `setup/create-app.sh`

### Using Client Certificate (Recommended for production)

- `DVA_TENANT_ID`: Azure AD tenant ID
- `DVA_CLIENT_ID`: Entra app ID
- `DVA_CLIENT_CERT_PATH`: Absolute path to the PEM-encoded certificate file
- `DVA_CLIENT_CERT_THUMBPRINT`: SHA-1 thumbprint of the certificate in hex (without spaces)

## API Permissions

**Note on HTTP status codes**: An HTTP 401 response means the token was rejected (wrong client secret, wrong tenant ID, or token expired); an HTTP 403 means the application has the permission but admin consent was not granted or the caller lacks the required role assignment. Both will appear in doctor output as failures with the HTTP status code and server detail message.

## Granting Permissions

### Admin Consent

WindowsDefenderATP and Microsoft Graph application permissions require admin consent. After running `setup/create-app.sh`, grant admin consent with:

```bash
az ad app permission admin-consent --id <APP_ID>
```

This requires a Global Administrator or Privileged Role Administrator in the tenant.

## Verification

Verify all permissions are correctly configured with:

```bash
python3 -m dva doctor
```

Each check prints one line in the format: `<API> <permission> ok|FAIL <detail>`

All checks must show `ok` status for the application to function.

## Setup Script

Create the app registration and service principal with:

```bash
./setup/create-app.sh --name defender-vuln-agent
```

For a dry run (print commands without executing):

```bash
./setup/create-app.sh --dry-run --name defender-vuln-agent
```

The script will output the required environment variables and manual steps.
